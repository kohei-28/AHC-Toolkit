# AHC Short Toolkit

A personal toolkit for short AtCoder Heuristic Contests.

## Purpose

This repository stores reusable code prepared before contests. Its goal is to reduce setup and testing time so that more of the contest can be spent designing and improving problem-specific solutions.

## Planned Contents

- Modular C++23 templates for common heuristic search techniques
- Local tools for running multiple test cases and comparing scores

## Development Policy

The toolkit is developed incrementally through practice on past problems. Components are added or revised only after their usefulness and interface have been tested in actual problem-solving workflows.

## Status

This project is in its early development stage.
